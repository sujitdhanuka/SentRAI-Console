Discover Models From a Codebase

Point this at the root of any application's source tree (e.g. /path/to/your-app/src). This runs a static, read-only scan — it pattern-matches for LLM/ML API calls, agent definitions, and scoring logic, then reports governance gaps against the 7 Sutras. It does not execute any code in the target directory. Results are candidates for a human to confirm, not a certification.
